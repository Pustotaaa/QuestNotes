# Квест-заметки

Нативное Android-приложение (Kotlin + Jetpack Compose): заметки в стиле Google Keep и необязательный РПГ-режим.

## Как получить APK

### Способ 1. Через GitHub (без Android Studio)
1. Создайте на github.com новый репозиторий (можно приватный).
2. Загрузите в него все файлы проекта, включая скрытую папку `.github`.
   Проще всего: `git init`, `git add .`, `git commit`, `git push` — или перетащить папки в веб-интерфейс GitHub.
3. Откройте вкладку **Actions**. Сборка запустится сама (около 5–8 минут).
4. Откройте завершённый запуск, внизу в разделе **Artifacts** скачайте `QuestNotes-debug-apk`.
5. Распакуйте архив, перекиньте `app-debug.apk` на телефон и откройте его.
   Android попросит разрешить установку из неизвестных источников — разрешите.

### Способ 2. Через Android Studio
1. Установите Android Studio и откройте папку проекта (File → Open).
2. Дождитесь синхронизации Gradle.
3. Build → Build Bundle(s) / APK(s) → Build APK(s).
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Что внутри
- Заметки: текст и чеклисты, цвета, закрепление, архив, корзина, поиск, автосохранение.
- Данные хранятся на телефоне (файл `data.json` во внутренней памяти приложения).
- РПГ (кнопка `⚔ N` рядом с поиском): уровень, опыт, задания, достижения.
  В списке любой заметки нажмите `⚔` у пункта, чтобы сделать его заданием (+10 / +25 / +50 XP).
  Опыт за пункт начисляется один раз.

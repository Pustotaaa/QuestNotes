# Квест-заметки

Заметки в стиле Google Keep, а рядом, на отдельной вкладке, необязательная РПГ: квесты из реальных дел, прокачка героя, автобой в подземелье, навыки из сундука, каталог серий и тестов по сферам жизни.

Сейчас это HTML-прототип, завёрнутый в Android-приложение (WebView на Kotlin). Работает офлайн, данные хранятся на телефоне.

## Как поставить на телефон

1. Откройте раздел **Releases** справа на странице репозитория и скачайте свежий `QuestNotes-*.apk` прямо с телефона.
2. Откройте файл. Android попросит разрешить установку из этого источника — разрешите.
3. Новые версии ставятся поверх старой, заметки и прогресс сохраняются.

> Если раньше стояла старая Compose-версия, удалите её один раз: она подписана другим ключом, и новая поверх неё не встанет.

Каждая сборка также лежит в **Actions → последний запуск → Artifacts → QuestNotes-apk** (архив, нужен вход в GitHub).

## Как выпустить новую версию

```bash
git tag v0.2.1
git push origin v0.2.1
```

GitHub Actions соберёт APK и опубликует его в Releases. Обычный push в `main` тоже собирает APK, но только в Artifacts.

## Устройство проекта

| Путь | Что там |
| --- | --- |
| `web/index.html` | Исходник прототипа: вся логика заметок и РПГ в одном файле |
| `tools/make_assets.py` | Превращает исходник в `app/src/main/assets/index.html`: локальные шрифты, отступы под системные панели |
| `app/src/main/assets/` | Готовая страница и шрифты Onest и Press Start 2P (лицензия OFL) |
| `app/src/main/java/.../MainActivity.kt` | WebView-обёртка: локальный https-адрес для страницы, отступы, кнопка «назад», цвет статус-бара |
| `app/debug.keystore` | Общий отладочный ключ, чтобы сборки ставились друг поверх друга |
| `.github/workflows/build.yml` | Сборка APK |

После правок в `web/index.html` запустите `python3 tools/make_assets.py` (CI делает это сам).

## Подпись для Google Play

`app/debug.keystore` открыт и подходит только для личной установки. Для публикации создайте свой ключ и добавьте в **Settings → Secrets and variables → Actions** три секрета:

- `QN_KEYSTORE_BASE64` — ключ в base64: `base64 -w0 release.p12`
- `QN_STORE_PASSWORD` и `QN_KEY_PASSWORD` — пароли

Workflow подхватит их автоматически. Учтите: APK с новым ключом не встанет поверх версии с отладочным.

## Сборка в Android Studio

Откройте папку проекта, дождитесь синхронизации Gradle и выберите **Build → Build APK(s)**.
